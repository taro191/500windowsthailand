# 500 Windows to Thailand — เว็บผู้ใช้ + ระบบผู้ดูแล (web)

โค้ด React ที่แปลงมาจากดีไซน์ Figma Make ใน `../design`
ตัวดีไซน์เดิมเป็น bundle ที่คอมไพล์แล้ว ส่วนโปรเจกต์นี้เขียนใหม่ให้อ่านและแก้ต่อได้ หน้าตาและการทำงานยังเหมือนเดิม

```bash
npm install
npm run dev        # http://localhost:5173 (ต้องรัน API ใน ../server ด้วย — Vite ส่ง /api, /uploads ไปที่ localhost:3001)
npm run build      # type-check + production build
```

Stack: React 19, TypeScript, Vite, Tailwind CSS 4, lucide-react

## สถานะ

ข้อมูลทั้งหมดมาจาก API ใน `../server` ส่วนต่อไปนี้ยังเป็นการจำลอง:

- Payment Gateway (บัตร) — ยังไม่ได้เลือกผู้ให้บริการ
- OTP ตอนยืนยันตัวตน (KYC) — แสดงรหัสบนหน้าจอ เพราะยังไม่มีผู้ให้บริการ SMS
- การโอนเงินออกให้ผู้ขาย — เงินสุทธิเข้ากระเป๋าผู้ขาย ผู้ดูแลโอนจริงเอง

การเรียก API อยู่ที่ `src/lib/api.ts` (client กลาง), `src/lib/store.ts` (ผู้ใช้) และ `src/lib/adminApi.ts` (ผู้ดูแล)

## การชำระเงิน

- **ทุกการใช้จ่าย (จับจอง/ซื้อต่อ):** หน้า `CheckoutModal` ตัดเงินจากกระเป๋าก่อน ถ้าไม่พอ (หรือผู้ใช้ไม่ใช้กระเป๋า) ให้เลือกช่องทางจ่ายส่วนที่เหลือ ธุรกรรมบันทึก `walletAmount` / `externalAmount` / `channelName`
- **ค่าโปรโมท:** ชำระตอนส่งคำขอ (กระเป๋าก่อน + ช่องทางอื่น) · Admin อนุมัติ = นับเป็นรายได้และโฆษณาขึ้นบอร์ด · ไม่อนุมัติ = คืนเงินเต็มจำนวนเข้ากระเป๋าทันที (ธุรกรรมประเภท `refund`) · การคืนกลับไปบัตร/บัญชีธนาคารต้องมี backend
- **เติมเงิน:** `TopUpModal` (เปิดจากเมนูบัญชี, แท็บกระเป๋าเงินใน Hub, เมนูมือถือ และหน้าชำระเงิน)
- **ช่องทางรับชำระเงิน:** พร้อมเพย์, บัญชีธนาคารหลายบัญชี, TrueMoney, บัตร (Gateway) — เพิ่ม/แก้/ปิดได้จากหน้า Admin

## ระบบผู้ดูแล (Admin) — รูปแบบ AdminLTE

เข้าได้เฉพาะผู้ใช้ `role: 'admin'` ผ่านปุ่ม **Admin** ที่ Header/เมนูมือถือ หรือ URL `#admin/<page>`
บัญชีผู้ดูแลสร้างจาก `ADMIN_EMAIL` / `ADMIN_PASSWORD` ใน env ของ server · บัญชีทดสอบ `admin@kapsulep.com` / `password123` มีเฉพาะเมื่อตั้ง `DEMO_TOOLS=true`

| กลุ่ม | เมนู | สถานะ |
|---|---|---|
| ภาพรวม | แดชบอร์ด | ใช้งานได้ |
| หน้าต่าง & เนื้อหา | จัดการหน้าต่าง (ค้นหา/กรอง 3,500 บาน, ถอดเนื้อหา, คืนบาน) | ใช้งานได้ |
| | ตรวจสอบเนื้อหา (รูป/ข้อความล่าสุด) | ใช้งานได้ |
| | พื้นที่โปรโมท (อนุมัติ → ขึ้นบอร์ด, ไม่อนุมัติ → คืนเงินเข้ากระเป๋า) | ใช้งานได้ |
| ผู้ใช้งาน | ผู้ใช้งาน & KYC (ค้นหา, กรองตามสิทธิ์/สถานะ/KYC, เปิด-ปิดใช้งานบัญชี, ระงับธุรกรรม, เพิกถอน KYC; เฉพาะ super admin: เพิ่มผู้ใช้, เปลี่ยนสิทธิ์แอดมิน/ผู้ใช้ทั่วไป) | ใช้งานได้ |
| การเงิน | ธุรกรรมทั้งหมด (+ ส่งออก CSV) | ใช้งานได้ |

| | รายงานรายได้ | ใช้งานได้ |
| ตั้งค่าระบบ | เพดานราคาขายต่อ (เพิ่ม/ลบช่วงอายุ) | ใช้งานได้ · มีผลทันที |

| | ตั้งค่าการเติมเงิน (ขั้นต่ำ/สูงสุด/ปุ่มลัด) | ใช้งานได้ |
| | สิทธิ์แก้ไขบาน (แก้ไขฟรีกี่ครั้ง/วัน, ค่าแก้ไขครั้งต่อไปที่หักจากกระเป๋า) | ใช้งานได้ · มีผลทันที |

## โครงสร้าง

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `../shared/` | types, ข้อมูลตั้งต้น (ภูมิภาค, หมวด, ธนาคาร) และกติกาที่ใช้ร่วมกับ server: ownershipRules, boardOrder, thaiTime, windowBadges, promo, identity, settings |
| `src/lib/api.ts` | client กลางสำหรับเรียก API (`{ success, error }`) |
| `src/lib/store.ts` | cache ข้อมูลจาก API และทุก action ของผู้ใช้: สมัคร, ล็อกอิน, KYC, จับจอง, ซื้อต่อ, ขายต่อ, แก้ไข, ไลค์, ติดตาม |
| `src/lib/adminApi.ts` | action ของผู้ดูแล |
| `src/lib/settings.ts`, `ownershipRules.ts`, `promo.ts` | ห่อกติกาจาก `shared/` ให้ใช้ค่าตั้งระบบที่โหลดจาก API |
| `src/components/` | UI แยกตามส่วน: board, window, payment, hub, auth, promo, layout, admin |
| `src/i18n/` | ปุ่มสลับภาษาไทย/อังกฤษ (แปลข้อความบนหน้าจอจากตารางคำแปล) |
| `index.html` | `window.KAPSULEP_CONFIG`: อีเมล/LINE รับคำขอโปรโมท และโฆษณาที่อนุมัติแล้ว |

## จุดที่ต่างจากดีไซน์ต้นฉบับ

**แก้บั๊ก**

- **ส่งคำขอโปรโมทไม่ได้:** โค้ดอ้างตัวแปร `selectedDate` ที่ไม่มีอยู่จริง ทำให้เกิด error ทุกครั้งที่กดส่ง
- **หน้ารายละเอียดเด้งกลับมาเอง:** ลิงก์แชร์ `#window-...` ถูกตรวจซ้ำทุกครั้งที่ข้อมูลบอร์ดเปลี่ยน ตอนนี้ตรวจเฉพาะตอนโหลดหน้าและตอนลิงก์เปลี่ยน
- **ผิดกฎ React Hooks:** ฟอร์มจับจองและฟอร์มแก้ไขเรียก `useState` หลัง `return null` ตอนนี้ parent จะแสดงฟอร์มเฉพาะเมื่อมีบานให้แสดง
- **ข้อมูล KYC ค้าง:** ฟอร์ม KYC ดึงเลขบัตรของผู้ใช้คนแรกที่เปิด ตอนนี้รีเซ็ตเมื่อสลับบัญชี

**ตัดโค้ดที่ไม่มีทางใช้งานได้**

- **การโอนกรรมสิทธิ์ฟรี:** ฟอร์มนี้ไม่มีปุ่มเปิด และฟังก์ชันจะคืน error เสมอตามกติกา "ไม่มีการโอนฟรี" จึงเหลือไว้แค่ `store.transferWindow()` ที่คืนข้อความแจ้งเหตุผล

**ส่วนที่มีอยู่แต่ยังไม่ได้เปิดใช้**

- **`ResetConfirmModal` + `store.resetAppData()`:** ในดีไซน์ไม่มีปุ่มไหนเปิดหน้านี้ จึงเก็บไว้รอใส่ปุ่มเมื่อต้องการ

**เปลี่ยนวิธีทำ**

- **ไม่ใช้ iframe แล้ว:** ดีไซน์เดิมห่อแอปไว้ใน iframe ตอนนี้แอปรันตรงๆ และคำนวณความสูงหน้าจอผ่าน `useViewportHeight`
- **ไอคอน:** ใช้ `lucide-react` แทนชุดไอคอนที่ฝังไว้
- **ฟอนต์:** โหลดจาก Google Fonts แทนการฝัง Prompt ไว้ใน CSS
- **รูปบานในกระเป๋าเงิน:** ถ้าไม่มีรูป จะแสดงช่องว่างแทนรูปจาก `via.placeholder.com`

## ข้อสังเกตจากดีไซน์ที่ควรตัดสินใจ

- **กติกาทั่วไป:** ราคาจับจอง, ค่าคอม, ระยะถือครอง ยังแก้จากหน้า Admin ไม่ได้ เพราะข้อความในหลายหน้าเขียนค่าไว้ตายตัว
- **เลขบัญชีจริง:** ช่องทาง SCB และ TrueMoney ในค่าเริ่มต้นยังเป็นช่องว่าง `[เลขบัญชี SCB]`, `[เบอร์ TrueMoney]`
